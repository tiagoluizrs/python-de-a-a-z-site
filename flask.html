Sobre este livro

Um sistema de gerenciamento de produtos, do zero à área administrativa

O Flask é um dos melhores frameworks Python da atualidade: flexível o bastante para as necessidades do usuário final e para o fluxo de trabalho de equipes, e com ótima integração com o SQLAlchemy, uma biblioteca ORM para trabalhar com diversos bancos de dados relacionais.

Neste livro você aprende a criar aplicações web e APIs REST robustas com Flask, SQLAlchemy e outras ferramentas Python. O projeto prático é um sistema de gerenciamento de produtos, com categorias, usuários e funções: um usuário pode ser limitado à API ou ter acesso também ao administrador, sempre com autenticação segura.

Ao final, a aplicação terá uma API e uma área administrativa completa, com templates personalizados.

FlaskSQLAlchemyAPI RESTJWTÁrea administrativaPadrão MVCFlask-MigrateRecuperação de senha por e-mail

O que você vai aprender

  • Montar um projeto Flask com Models, Routes, Controllers e Views (padrão MVC)
  • Trabalhar com banco de dados e migrações (SQLAlchemy e Flask-Migrate)
  • Fazer consultas com filtros, funções de agrupamento e cláusulas avançadas no SQLAlchemy
  • Criar e personalizar a área administrativa
  • Criar uma API REST que recebe e responde JSON
  • Proteger a aplicação com autenticação JWT e níveis de acesso
  • Enviar e-mails e implementar a recuperação de senha com token
