Python do zero ao avançado

Livro de Python do básico ao avançado

Python de A a Z é uma coleção de 5 volumes para aprender Python do zero ao avançado, em português: do primeiro print() ao código em produção, com exercícios, testes automatizados e todo o código em um repositório público.

Python do zero ao avançado em 5 volumes

A coleção foi pensada como um caminho. O primeiro volume é um livro de Python para iniciantes. Os seguintes levam você, volume a volume, até o nível profissional: dominar a linguagem, escrever software que outras pessoas conseguem manter, trabalhar com dados e produção, e projetar com padrões de projeto.

  • Volume 1: Fundamentos (Iniciante). Do ambiente ao Python do dia a dia: tipos, estruturas de dados, funções, texto, arquivos e biblioteca padrão.
  • Volume 2: Domínio da linguagem (Intermediário a avançado). Closures, geradores, o modelo de dados, orientação a objetos avançada e o CPython por dentro.
  • Volume 3: Engenharia e concorrência (Avançado). Projetos, testes, tipagem, SOLID, segurança e performance; threads, processos e asyncio.
  • Volume 4: Dados, mundo real e produção (Avançado, com foco em mercado). Bancos de dados, HTTP, Pandas e Polars, automação web, Docker, filas e pipelines.
  • Volume 5: Padrões de projeto (Avançado). Os padrões de projeto clássicos e os do dia a dia, na forma pythônica e com o custo medido.

Qual volume ler primeiro?

  • Nunca programou: comece pelo Volume 1. Nenhum conhecimento prévio é necessário.
  • Já programa em outra linguagem: use o Volume 1 como referência (capítulos 3 a 9) ou vá ao Volume 2.
  • Já escreve scripts em Python e quer entender a linguagem a fundo: Volume 2.
  • Quer escrever Python profissional, com testes, tipagem e concorrência: Volume 3.
  • Quer trabalhar com bancos de dados, APIs, análise de dados e produção: Volume 4.
  • Quer aprender padrões de projeto em Python: Volume 5, que pressupõe a base dos volumes anteriores.

O que você vai aprender

  • Montar um ambiente profissional com ambientes virtuais e o uv
  • Entender variáveis, tipos, memória, listas, dicionários e conjuntos
  • Dominar decoradores, geradores, o modelo de dados e a orientação a objetos avançada
  • Estruturar projetos, escrever testes, usar tipagem estática e aplicar SOLID
  • Escolher entre threads, multiprocessamento e asyncio com base em medições
  • Trabalhar com SQL, PostgreSQL, MySQL, SQLAlchemy, Redis e MongoDB
  • Consumir APIs, validar dados com Pydantic e analisar dados com Pandas e Polars
  • Levar o código para produção com Docker, filas e pipelines
  • Aplicar padrões de projeto na versão pythônica, sabendo quando não usar

Python e o mercado de trabalho

Vagas de Python costumam pedir mais do que sintaxe: uma base sólida, engenharia (testes, segurança e desempenho) e produção (bancos de dados, APIs, Docker e filas). Cada volume cobre uma etapa desse caminho. O Volume 4 reúne ainda 66 perguntas de entrevista técnica, com respostas, de júnior a sênior.

Como são os livros

São 2.490 páginas no total, escritas com o Python 3.15. Todo capítulo traz exemplos executáveis, as pegadinhas que derrubam quem está começando, exercícios com gabarito e testes automatizados. O código, os exercícios e os testes ficam no repositório da coleção no GitHub. Cada volume é uma obra de referência: não é preciso lê-lo de capa a capa.

Perguntas frequentes

Qual livro de Python devo ler se nunca programei?

O Volume 1, Fundamentos. Ele parte do zero absoluto e não exige nenhum conhecimento prévio de programação: instala o ambiente, explica variáveis, tipos e memória, e avança por coleções, funções, texto, arquivos, datas e a biblioteca padrão.

Esta coleção ensina Python do básico ao avançado?

Sim. O Volume 1 cobre a base. O Volume 2 aprofunda a linguagem (decoradores, geradores, modelo de dados, orientação a objetos avançada). O Volume 3 trata de engenharia e concorrência, o Volume 4 de bancos de dados, APIs, análise de dados e produção, e o Volume 5 de padrões de projeto.

Preciso ler os 5 volumes em ordem?

Não. Cada volume foi escrito para ser lido sozinho, com a lista de pré-requisitos no começo. Quem está começando deve seguir a ordem; quem já programa pode entrar direto no volume de que precisa.

Qual versão do Python os livros usam?

O Python 3.15, lançado em outubro de 2026. Recursos de versões anteriores trazem o selo da versão em que surgiram, e o Apêndice A do Volume 2 reúne as novidades do Python 3.8 ao 3.15.

Os livros têm exercícios?

Sim. Todo capítulo traz exercícios com gabarito e testes automatizados. Todo o código, os exercícios e os testes estão em um repositório público no GitHub, organizado por volume e por capítulo.

Onde comprar?
