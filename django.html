Sobre este livro

Uma aplicação de grande porte, completa e segura

O Django é o framework mais popular do Python: uma ferramenta completa para criar aplicações web de forma rápida e consistente. Dominá-lo permite construir aplicações grandes, usadas por empresas de todos os portes, e avançar na carreira com Python.

No livro você cria uma aplicação de grande porte, completa e segura, que se comunica via client/server, com painel administrativo, telas HTML, views, templates e formulários, além de um mergulho no Django ORM para trabalhar com banco de dados de forma avançada. O autor inclui dicas da sua experiência para aumentar a produtividade no uso do Django.

Para quem é

Para quem quer atuar ou ingressar no mercado de Python, com foco em desenvolvimento web com Django.

Django ORMAdminTemplates e formsAutenticação socialServiço de e-mailTestes unitáriosDeploy no Heroku

O que você vai aprender

  • Montar o projeto Django e as models, com upload de imagens
  • Personalizar o painel administrativo
  • Criar views, URLs, templates e formulários (incluindo model forms)
  • Consultar e alterar dados com o Django ORM e o QuerySet
  • Controlar o acesso com login_required e autenticação com redes sociais
  • Configurar o serviço de e-mail e a recuperação de senha
  • Escrever testes unitários, com TDD e cobertura de código
  • Fazer o deploy no Heroku
