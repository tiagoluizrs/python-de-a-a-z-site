Sobre este livro

Uma API REST segura, robusta e de alto desempenho, pronta para produção

Neste livro, você aprenderá a criar uma API RESTful com o Django REST Framework, o maior toolkit para APIs REST que existe para o ecossistema Django. Considerado uma das soluções mais robustas da atualidade para esse tipo de desenvolvimento, o framework permite criar APIs de alta performance com facilidade de implementação e uma documentação excelente e extremamente útil.

Utilizaremos o projeto de um Sistema de Gestão de Produtos como base para explorar conceitos profundos. Ao final, você não terá apenas uma API funcionando, mas um portfólio de código que segue os padrões exigidos por grandes empresas de tecnologia.

A estrutura é híbrida de propósito: capítulos inteiramente dedicados ao “mão na massa”, nos quais você constrói passo a passo o projeto ProductManager (com Docker, CI/CD, Redis e Celery), intercalados com capítulos de engenharia e arquitetura, sobre design de software, segurança ofensiva, performance e boas práticas.

Para quem é

Desenvolvedores que desejam não apenas “fazer funcionar”, mas entender a fundo como construir sistemas resilientes, seguros e escaláveis. Se você é iniciante, os primeiros capítulos dão uma base sólida; se já tem experiência, os capítulos finais sobre Docker, testes de carga, segurança ofensiva e Arquitetura Limpa vão desafiá-lo a elevar o nível técnico.

Pré-requisitos

Conhecimento básico em Python e Django (o livro Django de A a Z ajuda a reforçar) e familiaridade com a linha de comando.

Django REST FrameworkJWTSerializaçãoDockerCeleryRedisOpenAPI e SwaggerArquitetura limpa

O que você vai aprender

  • Fundamentos: serialização, ViewSets, Routers e autenticação JWT.
  • Qualidade: testes automatizados (unitários e integração), CI/CD e Clean Code.
  • Infraestrutura: Docker, Docker Compose e preparação para cloud.
  • Performance: caching com Redis, throttling, paginação e otimização de consultas (N+1).
  • Segurança: proteção contra ataques comuns (OWASP), permissões personalizadas e boas práticas de mercado.
